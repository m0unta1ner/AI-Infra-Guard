# aig-skill-promptbank

Post-processes confirmed `aig-skill-scan` findings into verifiable Prompt test cases.

The generator does not execute the scanned Skill. It reads the scan result and validates that every generated case points to an existing source file and valid line range.

## Usage

```bash
python main.py \
  --repo /path/to/skill \
  --scan-result /path/to/scan-result.json \
  --output /path/to/prompt-bank.jsonl \
  --summary-output /path/to/prompt-bank-summary.json \
  --model deepseek-v4-flash \
  --api-key "$LLM_API_KEY"
```

Only `Critical`, `High`, and `Medium` findings are converted. The default is three cases per finding, covering direct trigger, boundary case, and refusal case.

`--scan-result` accepts either the internal `result_meta` JSON emitted by AIG mode or SARIF 2.1.0 generated by standalone `aig-skill-scan`.
